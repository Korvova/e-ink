# E-Ink Display Project (Waveshare ESP32-S3-ETH + GoodDisplay 10.85")

Рабочий проект для `GDEM1085T51` через драйверы GoodDisplay (`Display_EPD_W21*`) и PlatformIO.

## Важно

- Для этого дисплея нужны обе линии выбора кристаллов: `CS` и `CS2`.
- Сейчас в `platformio.ini` активна распиновка **экрана 2** (через `build_flags`); в рантайме набор пинов переключается командой `p`.
- Порт ESP32-S3-ETH (CH343) на этом ПК: `COM29` (раньше был `COM9`, проверяй `pio device list`).
- Данные (`SDI`) и такт (`SCLK`) можно шарить между экранами.

## Веб-интерфейс (Ethernet)

Плата — Waveshare ESP32-S3-ETH (W5500 на GPIO 11/12/13, CS 14, INT 10, RST 9; в прошивке есть автоопределение,
второй набор пинов — YB-ESP32-S3-ETH). Сеть по DHCP; если аренда не пришла за 15 с (в лабораторном сегменте DHCP нет),
плата берёт **статический адрес 192.168.1.222** (маска /24, шлюз 192.168.1.1). Имя `eink.local` по mDNS.

- `http://192.168.1.222/` — страница: два поля (экран 1 / экран 2), размер шрифта (0 = автоподбор), жирный, предпросмотр, «Показать», «Очистить».
- `GET /status` — JSON: занятость, очередь, IP, последние тексты.
- `GET /frame.bmp` — последний отрисованный кадр 1360×480 (1 бит), ровно то, что ушло на панель; удобно проверять без камеры.
- `POST /show` (или GET) `screen=1|2&text=...&size=0&bold=1` — вывести текст; ответ 202, обновление ~20 с идёт в фоне.
- `POST /clear` `screen=1|2` — белый экран.

Пример из PowerShell:

```powershell
Invoke-WebRequest -Method Post http://192.168.1.222/show -Body @{screen=1; text="Привет`nмир"; size=0; bold=1}
```

## Шрифт

Текст рисуется TTF-шрифтом PT Sans (регулярный и жирный, лицензия OFL, подмножество латиница+кириллица, `data/*.ttf`
вшиты в прошивку через `board_build.embed_files`) библиотекой OpenFontRender. Многострочность через Enter,
размер 0 = максимальный, при котором текст влезает. Панель чёрно-белая, 4 градации серого в открытом коде
GooDisplay для GDEM1085T51 нет (по их сайту — «по запросу»), поэтому сглаживание не делается: пиксель чёрный при покрытии > 50 %.

## Команды в Serial (`115200`)

- `1` - белый экран (текущий экран)
- `2` - чёрный
- `3` - тестовый узор
- `t<текст>` + Enter - вывести текст TTF-шрифтом на текущий экран (UTF-8, `
` = перевод строки)
- `p` - переключить текущий экран 1 ↔ 2
- `i` - JSON статуса (IP, тексты)
- `h` - подсказка

Удобнее через скрипт: `python tools/serial_cmd.py COM29 t "Привет|мир"` (`|` = новая строка), `... COM29 --boot` — лог загрузки.

## Сборка и загрузка

Платформа — **pioarduino** (Arduino core 3.x, нужен для W5500 через `ETH.h`), PlatformIO Core ≥ 6.1.19.
Собирать из PowerShell/cmd, **не из Git Bash** (установщик инструментов ESP-IDF отказывает под MSys).
Каталог сборки вынесен в `C:/app/_pio_build/e-ink` — `ld.exe` не пишет map-файл в путь с кириллицей.

```bash
pio run -t upload
```

Monitor:

```bash
pio device monitor --baud 115200 --port COM29
```

## Как переключить проект на экран 1

Быстро: в мониторе отправить `p` (только для serial-команд; веб-интерфейс сам выбирает экран). Постоянно — через `build_flags`:

В `platformio.ini` поменяйте `build_flags` на:

```ini
-DEPD_PIN_MOSI=35
-DEPD_PIN_CLK=36
-DEPD_PIN_CS=37
-DEPD_PIN_CS2=40
-DEPD_PIN_RST=38
-DEPD_PIN_BUSY=39
```


```
На другом компе достаточно:

-e-ink.git
-открыть проект в PlatformIO
-проверить upload_port/monitor_port
-pio run -t upload
И можно сразу пользоваться.
```

## Шлейф дисплея (FPC-8617B → DESPI-C1085)

- Разъём на DESPI-C1085 **верхнеконтактный**: шлейф вставляется **золотыми контактами вверх**, к откидной крышке разъёма (от текстолита). Надпись `FPC-8617B` при этом тоже смотрит вверх.
- Проверено 2026-09-07: перепрошили ESP и вывели новую надпись `TEST` (команда `5`) — появилась, значит ориентация верная. Старая картинка на e-ink ничего не доказывает, экран хранит её без питания.
- Порядок: открыть крышку → вставить до упора без перекоса → защёлкнуть → только потом подавать питание.
